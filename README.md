# DefiFractal

DefiFractal enables self-organizing, decentralized crypto networks through adaptive fractal routing and auto-scaling smart-contract engine frameworks.

DefiFractal is built to be simple and practical, focusing on doing one thing well.

**Why DefiFractal?**

- DefiFractal enables self-organizing, decentralized crypto
- networks through adaptive fractal routing
- and auto-scaling smart-contract engine frameworks

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiFractal.git`
2. `cd DefiFractal`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
